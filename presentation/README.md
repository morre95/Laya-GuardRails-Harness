# Presentation

Slidev-presentation av projektet.

```bash
cd presentation
pnpm install
pnpm dev        # http://localhost:3030, presentatörsläge på /presenter
pnpm build      # statisk version i dist/
```

Siffrorna i `data/demo.ts` och på bilderna kommer från lokala traces, `labels.jsonl`,
träningsrapporten för `20261012T163824Z` och `comparisons/20261017-unseen`.
Uppdatera dem om du tränar eller jämför igen.
